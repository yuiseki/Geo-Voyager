# 0014 予想の外れを curriculum のご褒美にして、好奇心を持たせる

2026-10-17。

## 背景

- 探索 11 回目（2026-10-15〜17）では、curriculum が白紙から 61 Goal を立て、41 件に答えが出た。答えの出た Goal から一様ランダムに選んだ 12 件は、すべて正しかった。
- しかし、問いの多くは「最大はどれか」を 1 つ求める型だった。人口あたりの世帯数や、緯度と経度の区間分けを言い換えて繰り返した。
- 「同じ型の問いを続けない」とプロンプトに書いても、守られなかった。似た Goal を埋め込みで断る仕組みは、繰り返しを止める。しかし、何を調べると面白いかは教えない。
- お嬢様から、「予想が外れたらご褒美」という報酬の評価関数を設計し、curriculum に好奇心を持たせてほしいと頼まれた。予測の誤差を内発的な報酬にする好奇心の考え方（Schmidhuber、Pathak らの ICM）を、言葉で世界を調べる curriculum に移す。

## 決定

1. curriculum は、Goal と理由に加えて、答えの主な値の予想（数か名前を 1 つ）を、調べる前に書く。予想は「当てにいく本気の見積もり」として求める。返答は `Goal:`、`理由:`、`予想:` の 3 行で、予想の無い返答は断る。
2. 予想は Goal の始まりの記録（`events.jsonl` の goal_started）に残す。Planner、Generator、Critic には渡さない。答えが予想に引きずられないようにするため。
3. 答えが出たら、予想との食い違い（外れ度）を、モデルを使わずに測る（`geo_voyager/surprise.py`）。
   - 数: 答えが何桁ずれたか、|log10(答え / 予想)|。10 倍以上の外れは 1 で頭打ちにする。予想の「万」「億」を読む。答えに数が複数あれば、予想に最も近い数と比べる。どの数を予想したのかは分からないので、外れ度は大きく見積もらない側に倒す。
   - 名前: 答えにその名前があれば 0、無ければ 1。答えの JSON に、予想の名前の末尾と一致する 3 文字以上の名前があるときも 0（予想「横浜市営地下鉄ブルーライン」に答え「ブルーライン」。探索 19 回目で、同じ路線を外れ度 1 と数えた）。
   - 比べるものが無ければ（予想が数なのに答えに数が無い、など）、外れ度は無い。答えの出なかった Goal にも外れ度は無い。
4. 外れ度は、発見（`world.jsonl`）と、試した Goal の記録（`exploration.jsonl`）に、予想と一緒に残す。
5. curriculum には、発見ごとに「予想: … → 外れ度 0.36」を見せる。さらに、外れ度の大きい発見を、古さに関係なく上位 5 件まで見せる（1,500 字まで）。外れた所は世界が予想と違っていた所なので掘り下げ、外れ度の小さい主題からは離れるよう、プロンプトで促す。

## 考えたこと

- 外れ度をモデルに判定させる案は取らない。モデルの判定は curriculum に渡さない（[0011](0011-exploration-graph-checked-failures.md)）。
- ご褒美が外れを求めるため、curriculum がわざと外れた予想を書く恐れがある。プロンプトでは「外れるほど良い」とは言わず、本気の予想を求め、外れた所を掘り下げるよう促すだけにする。わざと外した予想が出ていないかは、記録を読んで確かめる。
- 似た Goal を断る仕組み（埋め込みで 0.95 以上）は残す。好奇心が同じ所を掘り続けても、言い換えは断られる。

## 確かめ方

白紙の World Graph と seed だけの Skill library から 30 Goal を流し（探索 12 回目）、探索 11 回目の最初の 30 Goal と比べる。ただし、探索 11 回目の最初の 30 Goal には、似た Goal を断る仕組みが無かった。

- 外れ度の推移（掘り下げた先で、予想が当たるようになるか）
- 問いの型と主題の幅
- 答えの出た割合、一様ランダムな 6 件の正しさ
- わざと外した予想の有無
